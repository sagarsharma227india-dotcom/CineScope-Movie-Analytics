# 🎬 CineScope — Movie Analytics

> Exploratory analysis of 9,827 movies using Python to uncover patterns in genres, ratings, popularity, and release trends.

## 📌 Project Overview

CineScope explores movie data through **data cleaning, exploratory analysis, and visualization to identify meaningful patterns and insights.

## 🎯 Key Questions

- Which genres are most common?
- How are movies distributed by voting category?
- Which movies have the highest and lowest popularity?
- Which year had the highest number of movie/genre records?
- Which languages are most represented?

## 🛠️ Tech Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 🔧 Data Preparation

- Data type and duplicate checks
- Date conversion and year extraction
- Missing-value analysis
- Vote-average categorization
- Multi-genre splitting and normalization
- Genre-level analysis using `explode()`

## 💡 Key Insights

- **Drama** is the most frequently represented genre.
- **Spider-Man: No Way Home** has the highest popularity score.
- **2021** has the highest number of movie/genre records in the prepared dataset.

> Note: Genre explosion means some analyses represent movie-genre records rather than unique movies.
